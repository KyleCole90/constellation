# Workspace store API

For screens. Import from `~/stores/workspace` and `~/stores/selectors`. Types are in `~/stores/types`.

## Reading

`useWorkspace(selector)` is the hook. A selector must return a stable value, because zustand 5 loops on a fresh object every render. The selectors below are memoized per state, so they are safe. Anything you build inline needs `useShallow`.

```ts
const rows = useWorkspace(selectQueueRows);
const status = useWorkspace((s) => selectThreadStatus(s, threadId));
```

| Selector                                                                   | Returns                                                                                                                                                                                                                                                                                              |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `selectQueueRows(state, assignment?, withMissing?)`                        | `QueueRow[]`, oldest due first, then nothing turned in last (a stable key, so a posted grade never moves a row), then most late, then name. Sent rows stay with `open: false`. `withMissing` adds students with nothing turned in (`missing: true`); only a grading thread's own list asks for them. |
| `selectWhatsDue(state, now)`                                               | `DueGroup[]`: past, today, week, later, then undated work to grade, oldest submission first. Pass `state.now()`.                                                                                                                                                                                     |
| `selectCalendar(state, now)`                                               | `CalendarData`: every dated assignment with its day offset, including closed ones What's due drops, the undated count, and each connected school's courses. Pass `state.now()`.                                                                                                                      |
| `selectInboxRows(state)`                                                   | `InboxRow[]` across schools, newest first. A sent change is dropped from the row once the student writes after it.                                                                                                                                                                                   |
| `selectDueExtras(state)`                                                   | Unsent announcements, drafted or not, and unread conversations for What's due.                                                                                                                                                                                                                       |
| `selectWorkStages(state)`                                                  | Started work that is stuck or waiting on approval, keyed by assignment or conversation ref. What's due ranks it first.                                                                                                                                                                               |
| `selectCourseAnnouncements(state, course)`                                 | The provider's posts for a course, newest first.                                                                                                                                                                                                                                                     |
| `selectGradebook(state, course)`                                           | `Gradebook`: rows by assignment. `pending` sits beside `grade`, never in place of it.                                                                                                                                                                                                                |
| `selectCourseOverview(state, course, now)`                                 | `CourseOverview` stats.                                                                                                                                                                                                                                                                              |
| `selectThreadName(state, threadId)`                                        | What to call the thread's work on any screen. A grading thread is `Grade <short title>`, an announcement thread takes its draft's title, a replies thread names the person on screen and counts the rest. Don't show `thread.title` directly.                                                        |
| `selectHandoffName(state, handoff)`                                        | What a handoff card in a chat calls its work: the one student for a single reply, the people it drafted for when it handed off every reply in a course, else `selectThreadName`. A later send doesn't change it.                                                                                     |
| `selectThreadStatus(state, threadId)`                                      | `ThreadStatus` for a sidebar pill or a handoff card, or null for none. A North Star chat only ever shows Working. Home shows nothing.                                                                                                                                                                |
| `selectSource(state, source)`                                              | `SourceView` with the course an answer line opens, or null when the thing is gone.                                                                                                                                                                                                                   |
| `selectCourseWaiting(state, course)`, `selectSchoolWaiting(state, school)` | `Waiting`: what needs the teacher, counted by kind (`attention`, `ready`, `approval`, `grade`, `unread`). Each piece of work counts once. Work waiting on a reconnect stays under `grade` or `unread`, because the school's dot says it.                                                             |
| `selectSchoolCoverage(state)`                                              | `SchoolCoverage`: schools with synced work, which a school filter offers, and disconnected schools, whose work no screen shows.                                                                                                                                                                      |
| `selectSchoolGap(state)`                                                   | `"none"` when no school was added, `"disconnected"` when every school is, else null. The screens that show school work say to add or reconnect one instead.                                                                                                                                          |
| `selectSetupOffers(state)`                                                 | `SetupOffer[]`: new courses at connected schools, with the thread once one is started.                                                                                                                                                                                                               |
| `selectSetupView(state, course)`                                           | `SetupView`: the setup, its derived stage, live job, review rows, readiness, and any template change.                                                                                                                                                                                                |

State fields: `schools`, `connections`, `onboarding`, `aiSource`, `cache`, `changes`, `blanks`, `threads`, `setups`, `newCourses`, `prefs`, `handoffs`, `notice`, `working`, `syncing`, `courseReads`, `setupLive`, `setupOptions`, `resetAt`.

`blanks` holds blank forms nobody has touched, in memory only. No selector over work counts them. A screen reads `changes[id] ?? blanks[id]` for a focused form. Read the AI gate with `useAiOn()`, never `aiSource`. `schools` starts empty. Only `addSchool` grows it, so every school in it was connected at least once. A workspace saved by version 2 loads with every school, connection, change, and thread kept.

For a change, use `summarize(record)` from `~/domain/change` to get the label, tone, recovery, and `missing`, the blanks that stop approval. No screen should branch on `state.tag` to work out what to offer.

## Actions

Reach them through `useWorkspace((s) => s.sendChanges)`, or `workspaceStore().getState()` outside React.

| `boot()`                                                                                              | Run once at app start. Reconciles the vault, recovers interrupted sends, and restarts handed-off work a reload cut short. Moves a saved conversation off home into its own chat. Syncs every connected school, as the network coming back does, and the desktop app again every 15 minutes, or sooner after a failure. Reads only from the LMS.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `now()`                                                                                               | The app clock, in epoch ms: the demo clock while every school is a demo school, real time once any real school joins. | `aiOn()`                                                                                              | The one AI gate. True when `aiSource` is not `"none"`, or when the store was built with `aiAlways`, as the test rig does.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `enrollmentFor(school)`                                                                               | What a token form renders for a school already added. It has no vendor branch.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `newSchoolEnrollment()`                                                                               | The same for a school not added yet: field label, steps, `addressPlaceholder`, and `tokenPageUrl(host)`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `demoHosts()`                                                                                         | Addresses the demo fill offers. A failed replacement keeps the token that was working.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `addSchool(host, new Secret(raw), onStage?)`                                                          | `Result<School, string>`. `host` comes from `parseSchoolHost` in `~/domain/ids`, the only way to make a `SchoolHost`. | `removeSchool(school)`                                                                                | Forgets the token and drops the school with its connection and cache. | `addAiKey(new Secret(raw))`, `chooseOnDeviceModel()`, `turnOffAi()`                                   | Set `aiSource` to `key`, `on-device`, or `none`. The key is vault only, and leaving `key` forgets it. Turning AI on drops untouched blanks. Saved drafts stay either way. A reload with the key gone from the vault turns AI off.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `scopeWordsFor(school)`                                                                               | The connection's permissions in plain words, from the provider. Returns a fresh array, so select it with `useShallow`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `syncSchool(school)`                                                                                  | Resolves false on failure. The old cache stays, `connection.syncError` is set, and `lastSyncedAt` holds the age.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `openSubmission(thread, ref)`, `openConversation(thread, ref)`, `openAnnouncement(thread, courseRef)` | Returns the `ChangeId`. Reuses a live change for that target. With AI on, runs the agent, except that `openSubmission` drafts only with `fill: "draft"`: opening one spends no model call, returns null, and leaves the screen to offer Draft with Claude or Grade it yourself (`fill: "by-hand"`, a blank form). ## Approving

Only `src/renderer/components/ApproveButton.tsx` may mint a witness, and a structure test fails the suite otherwise. It should fingerprint the record it is rendering, so an edit that wins the race makes the click stale:

```ts
const witness = ApprovalWitness.fromClick(event.nativeEvent, [
  { changeId: record.id, fingerprint: fingerprintOf(record) },
]);
if (witness)
  dispatchUser(record.id, {
    type: "approve",
    witness,
    at: isoTime(now()),
  });
```

For a batch, pass one target per change and dispatch once per change with the same witness.
